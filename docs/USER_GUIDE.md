# 사용 가이드

배포: https://blockshot-eta.vercel.app · 단축키 전체: [SHORTCUTS.md](./SHORTCUTS.md)

## 화면 구성

| 영역 | 역할 |
| --- | --- |
| 상단 시점 버튼 | **🎬 컷 재생** 샷 리스트대로 카메라를 바꿔 가며 보기(보기 전용) · **🧭 자유 시점** 편집용 시점 · **📷 카메라** 그 카메라로 보기 |
| 상단 툴바 | ＋추가(인물/카메라/소품), 실행 취소, 이동/회전 기즈모, 스냅, 열기/저장, AI·스크립트 |
| 오른쪽 패널 | **장면**(목록·속성) · **샷**(샷 추가/분할/길이/카메라/프롬프트) · **AI/스크립트** · **렌더** |
| 하단 | 렌즈 프리셋·화면비, 타임라인(재생, ● REC, 샷 블록, 선택 오브젝트의 키 ◆) |

## 1. 배치하기 (자유 시점)

1. **🧭 자유 시점**(V). 마우스 좌클릭 드래그로 둘러보기, 휠로 확대.
2. **＋추가**에서 인물·소품·카메라를 추가하거나, 뷰포트/목록에서 클릭해 선택.
3. 기즈모로 이동(W), 회전(E), 크기(R). 스냅(S)은 0.1m / 15° / 0.1배. 인물의 크기는 키(비율 유지)로 바뀌고, 정확한 값은 속성 패널에 입력.
4. 속성 패널에서 이름·색·키·포즈·렌즈·조준 대상을 수정.

## 2. 애니메이션 만들기 — 세 가지 방법

**A. 키프레임** (인물·카메라)
1. 🧭 자유 시점에서 인물(또는 카메라)을 선택하고, 타임라인을 **0초**에 둔 채 시작 위치로 옮긴 뒤 **`K`** — 첫 키.
2. 타임라인을 **3초**로 옮기고 인물을 끝 위치로 옮기면 **자동으로 3초에 키**가 생깁니다(키가 이미 있는 속성은 움직이는 순간 키가 찍힘). 포즈·렌즈를 바꿔도 마찬가지.
3. 재생(Space)하면 0→3초 사이를 이동합니다. 타임라인의 노란 ◆를 클릭하면 그 시간으로, `Alt+K`로 그 시간의 키 삭제.
- 툴바 **◆ 자동 키**(Shift+K)를 켜 두면 1번의 `K` 없이 움직일 때마다 바로 키가 찍힙니다.
- 소품은 아직 애니메이션되지 않습니다(위치·회전·크기는 전체 시간에 적용).

**B. 레코딩** — 인물이나 카메라를 선택하고 **● REC**(Shift+R). 현재 시간부터 재생되며:
- 인물: `WASD`로 걷기(보고 있는 시점 기준), `Shift`로 달리기. 걷기/달리기 포즈는 자동.
- 카메라: `WASD` 이동, `R/F` 높이, 화살표 팬·틸트, `Z/X` 줌.
- `Space`/`Esc`로 정지하면 동선이 키로 저장됩니다(구간 안의 기존 키는 교체, Ctrl+Z로 취소).
- 팁: 카메라를 레코딩할 땐 그 카메라 시점(📷)에서, 인물은 자유 시점이나 다른 카메라 시점에서 하면 편합니다.

**C. AI / 스크립트** — 오른쪽 **AI/스크립트** 탭에서 프롬프트를 복사해 ChatGPT·Claude 등에 붙여넣고, 결과(JSON 또는 스크립트)를 다시 붙여넣기.

## 3. 카메라 잡기

- 자유 시점에서는 **우상단 미리보기 창**에 선택한 카메라(없으면 현재 샷 카메라) 화면이 보입니다. 카메라를 기즈모로 옮기면 미리보기가 따라 바뀝니다.
- **📐 현재 자유 시점으로 맞추기**(카메라 속성): 자유 시점에서 원하는 구도를 잡고 누르면 카메라가 그 위치·방향으로 이동. ＋추가 → "카메라 (현재 자유 시점)"으로 새로 만들 수도 있습니다.
- **📷 카메라 시점 + 🎮 카메라 조작 ON**: 화면을 드래그하면 카메라 자체가 조준점 주위로 돌고(좌), 다가가고(휠), 평행 이동(우)합니다. 놓으면 저장.
- 회전 도구(E)로 카메라를 돌리면 조준 대상이 해제되고 회전값으로 바뀝니다. 다시 인물을 따라가게 하려면 속성 → 조준에서 지정하세요.
- 렌즈는 하단 렌즈 바 또는 속성 패널(mm). 화면비를 바꾸면 뷰포트가 그 비율로 고정됩니다.

## 4. 컷 편집

**🎬 컷 재생**으로 들어가면 하단 타임라인이 **편집 트랙**으로 바뀝니다. 샷이 순서대로 이어 붙은 클립으로 보이고, 재생하면 샷마다 해당 카메라로 전환됩니다.

- **✂ 자르기**: 재생 헤드 위치에서 현재 샷을 둘로.
- **⧉ 복제** 후 카메라만 바꾸기: 같은 연기를 다른 앵글로 — A 와이드 → B 클로즈업 → A로 돌아오는 커버리지 편집.
- **⊕ 합치기**: 다음 샷과 하나로(같은 카메라, 장면 시간이 이어질 때).
- **잘라내기/복사/붙여넣기**(Ctrl+X/C/V), **◀ ▶** 또는 클립 드래그로 순서 이동, **Delete**로 삭제.
- 클립 **양 끝을 드래그**하면 그 샷이 보여 주는 장면 구간(In/Out)이 줄거나 늘어납니다.
- 샷 탭에서는 카메라, In/Out 숫자, 설명, AI 영상 프롬프트를 편집합니다.

샷은 "장면의 몇 초부터 몇 초까지를 어느 카메라로"이므로, 인물 동작(장면)은 그대로 두고 편집만 자유롭게 바꿀 수 있습니다.

## 5. 영상 렌더링

툴바 **🎞 영상 렌더**(또는 오른쪽 **렌더** 탭) → 구간(편집본 전체 또는 샷 하나)(전체/샷), 카메라(샷 순서/고정), 패스(Beauty/Depth), 해상도 → **🎞 영상 렌더**.
- 브라우저 안에서 프레임 단위로 렌더(끊김 없음), Chrome/Edge 최신 권장. 결과는 MP4(H.264) 미리보기 + 다운로드.
- **camera.json**: 프레임별 카메라 위치·회전·초점거리 (카메라 컨트롤 모델용).
- **🖼 현재 프레임 PNG**: image-to-video 모델의 첫 프레임용.
- 출력에는 그리드·카메라 표시·이름표 같은 편집 보조 요소가 나오지 않습니다.

## 6. 저장

자동 저장(브라우저 IndexedDB). **프로젝트 저장**으로 `.blockshot.json` 다운로드, **열기** 또는 드래그 앤 드롭으로 불러오기.
