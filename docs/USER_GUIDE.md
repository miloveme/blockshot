# 사용 가이드

배포: https://blockshot-eta.vercel.app · 단축키 전체: [SHORTCUTS.md](./SHORTCUTS.md)

## 화면 구성

메뉴·단축키·⌘K 명령 팔레트·우클릭 메뉴가 모두 같은 명령을 실행한다 ([EDITOR_API.md](./EDITOR_API.md)). 막히면 `Ctrl/⌘+K`를 누르고 하고 싶은 일을 적는다. 맞는 명령이 없으면 그 문장을 그대로 AI에게 요청할 수 있다.

| 영역 | 역할 |
| --- | --- |
| 메뉴바 | 파일 · 편집 · 추가 · 오브젝트 · 애니메이션 · 카메라 · 컷 편집 · 보기 · AI · 도움말, 제목, 명령 검색(⌘K), 링크 · AI · 렌더 버튼 |
| 툴 레일 (왼쪽 끝) | 이동/회전/크기(W/E/R), 경로 찍기(P), 스냅(S), 자동 키, 녹화, 명령 검색, 단축키 |
| 왼쪽 패널 (Alt+1) | **아웃라이너**(인물·소품·카메라, 검색, 우클릭 메뉴, 카메라 더블클릭 = 그 시점) · **에셋** |
| 뷰포트 바 | 시점 **편집**(V) · **카메라**(1–9) · **컷**(0), 카메라 선택, 레이아웃(3D/분할/탑뷰, T), 렌즈 칩, 화면비 |
| 오른쪽 패널 (Alt+2) | **속성**(선택 없으면 장면 출력·공간) · **샷** · **AI** · **렌더**. 숫자 칸은 이름표를 끌어 조절(Shift 미세, Alt 크게) |
| 타임라인 (Alt+3) | 재생·키·REC·자동 키 + **도프시트**(오브젝트별 동작 블록과 키 ◆) / **컷 편집** 트랙 |
| 상태 바 | 모드, 선택, 상황별 키 힌트, 시간·프레임 |

## 1. 배치하기 (자유 시점)

1. **🧭 자유 시점**(V). 마우스 좌클릭 드래그로 둘러보기, 휠로 확대.
2. 메뉴 **추가**(인물은 Shift+A)에서 인물·소품·카메라를 추가하거나, 뷰포트/목록에서 클릭해 선택.
3. 기즈모로 이동(W), 회전(E), 크기(R). 스냅(S)은 0.1m / 15° / 0.1배. 인물의 크기는 키(비율 유지)로 바뀌고, 정확한 값은 속성 패널에 입력.
4. 속성 패널에서 이름·색·키·포즈·렌즈·피사체 고정 대상을 수정.

## 2. 애니메이션 만들기 — 세 가지 방법

**A. 키프레임** (인물·카메라)
1. 🧭 자유 시점에서 인물(또는 카메라)을 선택하고, 타임라인을 **0초**에 둔 채 시작 위치로 옮긴 뒤 **`K`** — 첫 키.
2. 타임라인을 **3초**로 옮기고 인물을 끝 위치로 옮기면 **자동으로 3초에 키**가 생깁니다(키가 이미 있는 속성은 움직이는 순간 키가 찍힘). 포즈·렌즈를 바꿔도 마찬가지.
3. 재생(Space)하면 0→3초 사이를 이동합니다.
- **키 삭제**: 타임라인 ◆를 **우클릭**, 또는 ◆를 클릭해 그 시간으로 간 뒤 속성 패널 **◇ 이 시간 키 삭제**(Alt+K). 회색 ◆(걷기 같은 액션이 만든 키)도 지워지며, 그 속성의 나머지 동작은 유지됩니다.
- 타임라인의 **자동 키**(Shift+K)를 켜 두면 1번의 `K` 없이 움직일 때마다 바로 키가 찍힙니다.
- 소품은 아직 애니메이션되지 않습니다(위치·회전·크기는 전체 시간에 적용).

**B. 레코딩** — 인물이나 카메라를 선택하고 **● REC**(Shift+R). 현재 시간부터 재생되며:
- 인물: `WASD`로 걷기(보고 있는 시점 기준), `Shift`로 달리기. 걷기/달리기 포즈는 자동.
- 카메라: `WASD` 이동, `R/F` 높이, 화살표 팬·틸트, `Z/X` 줌.
- `Space`/`Esc`로 정지하면 동선이 키로 저장됩니다(구간 안의 기존 키는 교체, Ctrl+Z로 취소).
- 팁: 카메라를 레코딩할 땐 그 카메라 시점(📷)에서, 인물은 자유 시점이나 다른 카메라 시점에서 하면 편합니다.

**C. AI / 스크립트** — 오른쪽 **AI/스크립트** 탭에서 프롬프트를 복사해 ChatGPT·Claude 등에 붙여넣고, 결과(JSON 또는 스크립트)를 다시 붙여넣기.

## 3. 카메라 잡기

- 자유 시점에서는 **우상단 미리보기 창**에 선택한 카메라(없으면 현재 샷 카메라) 화면이 보입니다. 카메라를 기즈모로 옮기면 미리보기가 따라 바뀝니다.
- **📐 현재 자유 시점으로 맞추기**(카메라 속성): 자유 시점에서 원하는 구도를 잡고 누르면 카메라가 그 위치·방향으로 이동. ＋추가 → "카메라 (현재 자유 시점)"으로 새로 만들 수도 있습니다.
- **📷 카메라 시점 + 🎮 카메라 조작 ON**: 화면을 드래그하면 카메라 자체가 주시점(피사체 고정 지점) 주위로 돌고(좌), 다가가고(휠), 평행 이동(우)합니다. 놓으면 저장.
- 회전 도구(E)로 카메라를 돌리면 피사체 고정이 풀리고 회전값으로 바뀝니다. 다시 인물을 따라가게 하려면 속성 → 피사체 고정에서 지정하세요.
- **피사체 전환**(카메라 속성): 숏 안에서 카메라가 다른 피사체로 옮겨 가는 연출. 시작 시간·새 피사체·전환 시간(초)을 정하면 그 시간 동안 팬·틸트로 넘어갑니다. 전환 시간 0은 즉시 전환(컷 지점용). 보통은 피사체가 바뀌면 컷을 나누는 것이 기본입니다.
- 렌즈는 하단 렌즈 바 또는 속성 패널(mm). 화면비를 바꾸면 뷰포트가 그 비율로 고정됩니다.

## 4. 컷 편집 (캡컷·프리미어 방식)

**🎬 컷 재생**으로 들어가면 하단이 **편집 타임라인**(눈금자 + 클립 트랙)으로, 오른쪽 **편집** 탭이 클립·소스·보관함으로 바뀝니다.

**자르기**
- **면도날(B)**: 클립의 원하는 위치를 클릭하면 거기서 잘립니다. 여러 번 자를 수 있습니다.
- **재생헤드 자르기(Ctrl+B)**: 재생 헤드 위치에서.

**중간 잘라내기**
- 잘라낸 조각을 클릭해 선택 → **Delete**: 지우고 뒤를 당깁니다(리플).
- 또는 재생 헤드를 옮겨 **I**(In), **O**(Out)로 구간을 찍고 **Delete**: 그 구간만 정확히 빠집니다.

**붙이기·옮기기**
- **Ctrl+X / C** 후 재생 헤드를 원하는 곳에 두고 **Ctrl+V**: 클립 중간이면 갈라서 끼워 넣습니다.
- 클립을 **끌어서** 다른 편집점으로 옮기기, **Shift+클릭**으로 여러 개 선택 후 한꺼번에 삭제·복사.
- 클립 양 끝 드래그로 트림, **합치기**로 이어지는 같은 카메라 클립을 하나로.

**다시 가져오기 (소스·보관함)**
- **소스**: 카메라별 전체 테이크(장면 0초~끝). 타임라인으로 끌어다 놓거나 **삽입**을 누르면 재생 헤드 위치에 들어가고, 거기서 다시 자르면 됩니다.
- **보관함**: 클립이나 In/Out 구간을 **📥 보관함**에 저장해 두고 언제든 다시 꺼내 넣을 수 있습니다(프로젝트 파일에 함께 저장).

샷은 "장면의 몇 초부터 몇 초까지를 어느 카메라로"이므로, 인물 동작(장면)은 그대로 두고 편집만 자유롭게 바꿀 수 있습니다. 모든 편집은 Ctrl+Z로 되돌릴 수 있습니다.

## 5. 영상 렌더링

메뉴바 **렌더** 버튼(Ctrl/⌘+Shift+E, 또는 오른쪽 **렌더** 탭) → 구간(편집본 전체 / 샷 하나 / **직접 지정**), 카메라(샷 순서/고정), 패스(Beauty/Depth), 해상도 → **🎞 영상 렌더**.
- **직접 지정**: 시작·끝(초)을 입력하거나, 재생 헤드 위치 버튼 또는 컷 편집에서 찍은 **In/Out** 버튼으로 채운다. 샷 순서로 렌더하면 편집본 시간(컷 편집 눈금, 샷을 넘나들어도 됨), 카메라 하나를 고정하면 장면 시간 기준.
- 브라우저 안에서 프레임 단위로 렌더(끊김 없음), Chrome/Edge 최신 권장. 결과는 MP4(H.264) 미리보기 + 다운로드.
- **camera.json**: 프레임별 카메라 위치·회전·초점거리 (카메라 컨트롤 모델용).
- **🖼 현재 프레임 PNG**: image-to-video 모델의 첫 프레임용.
- 출력에는 그리드·카메라 표시·이름표 같은 편집 보조 요소가 나오지 않습니다.

## 6. 저장

자동 저장(브라우저 IndexedDB). **프로젝트 저장**으로 `.blockshot.json` 다운로드, **열기** 또는 드래그 앤 드롭으로 불러오기.
