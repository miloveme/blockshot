# 단축키

입력 필드(텍스트·숫자·셀렉트)에 포커스가 있으면 단축키는 동작하지 않는다. 타임라인 슬라이더·색상 선택기는 예외(단축키 유지).

| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 정지 |
| `K` | 선택한 인물/카메라에 **현재 시간의 키** 추가 (인물: 위치·회전·포즈 / 카메라: 위치·렌즈) |
| `Alt+K` | 선택 오브젝트의 현재 시간 키 삭제 (액션으로 생긴 회색 키 포함) |
| 타임라인 ◆ 우클릭 | 그 키 삭제 (속성 패널의 ◇ 이 시간 키 삭제 버튼도 동일) |
| `Shift+K` | **자동 키** 켜기/끄기 — 켜면 인물·카메라를 움직이거나 렌즈·포즈를 바꿀 때마다 현재 시간에 키 |
| `Delete` / `Backspace` | 선택 오브젝트 삭제 (관련 액션·트랙·샷 참조도 정리) |
| `W` / `E` / `R` | 기즈모 이동 / 회전 / 크기 (소품: 축별 크기 · 인물: 키를 비율 유지로 · 카메라: 해당 없음) |
| `S` | 스냅 켜기/끄기 (이동 0.1 m, 회전 15°) |
| `Ctrl/⌘+Z` | 실행 취소 |
| `Ctrl/⌘+Shift+Z`, `Ctrl/⌘+Y` | 다시 실행 |
| `Shift+R` | 선택한 인물/카메라 **레코딩 시작** (현재 시간부터 재생하며 키보드 조작을 기록) |
| `V` | 자유 시점 (편집) |
| `0` | 컷 재생(샷 순서대로) 시점 |
| `1`–`9` | N번째 카메라 시점 |

## 🎬 컷 재생(편집) 시점

| 키 / 동작 | 효과 |
| --- | --- |
| `Ctrl/⌘+X` · `C` · `V` | 현재 샷 잘라내기 · 복사 · 현재 샷 뒤에 붙여넣기 |
| `Delete` / `Backspace` | 현재 샷 삭제 (뒤 샷들이 당겨짐) |
| `Alt+←` / `Alt+→` | 현재 샷을 앞/뒤로 이동 |
| 클립 클릭 | 그 샷으로 이동 |
| 클립 드래그 | 놓은 위치의 샷 자리로 순서 이동 |
| 클립 양 끝 드래그 | 장면 시간 In/Out 트림 (한 번의 Ctrl+Z로 취소) |
| ✂ 자르기 · ⊕ 합치기 · ⧉ 복제 | 재생 헤드에서 자르기 · 다음 샷과 합치기(같은 카메라, 이어지는 장면 시간) · 바로 뒤에 복제 |

## 레코딩 중 (● REC)

| 키 | 인물 | 카메라 |
| --- | --- | --- |
| `W` `A` `S` `D` | 보고 있는 시점 기준 앞·왼쪽·뒤·오른쪽 걷기 | 앞·왼쪽·뒤·오른쪽 이동 |
| `Shift` | 달리기 | 빠르게 이동 |
| `R` / `F` | — | 위 / 아래 |
| `←` `→` `↑` `↓` | — | 좌우 팬 / 상하 틸트 (조준 대상이 없는 카메라만) |
| `Z` / `X` | — | 줌 아웃 / 줌 인 (초점거리) |
| `Space` / `Esc` | 정지 → 키로 저장 | 정지 → 키로 저장 |

녹화 구간의 기존 키는 새 동작으로 교체되고, 구간 밖 동작은 유지된다. 한 번의 Ctrl+Z로 취소.

## 카메라 조작 (📷 카메라 시점에서 🎮 카메라 조작 ON)

| 마우스 | 동작 |
| --- | --- |
| 좌클릭 드래그 | 조준점을 중심으로 카메라 회전(오빗) |
| 휠 | 조준점 쪽으로 다가가기 / 멀어지기 |
| 우클릭 드래그 | 팬 (조준 대상이 인물 참조일 때는 비활성) |

놓는 순간 저장된다(위치가 애니메이션 중이면 현재 시간에 키).

## 편집 규칙

- 기즈모·속성 패널로 위치/회전/렌즈/포즈를 바꿀 때, 그 속성에 **키가 하나라도 있거나**(수동 키·액션) **자동 키가 켜져 있으면** 현재 시간에 키가 추가된다. 그 외에는 기본값(모든 시간)이 바뀐다.
- 수동 키가 처음 생길 때 기존 모션(액션이 만든 키)은 수동 트랙으로 복사되어 유지된다. 이후 해당 속성은 `actions` 대신 수동 트랙이 우선한다(SCENE_SPEC의 "tracks override").
- 모든 편집은 undo 한 단계(최대 100). 파일 열기/AI 임포트는 히스토리를 초기화한다.
