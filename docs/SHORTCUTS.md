# 단축키

모든 단축키는 명령 레지스트리(`apps/web/src/lib/commands.ts`, [EDITOR_API.md](EDITOR_API.md))에서 나온다. 에디터에서 `?`를 누르면 전체 목록이 보인다. 키는 물리 키 기준이라 한글 입력 상태에서도 동작한다. 입력 필드(텍스트·숫자·셀렉트)에 포커스가 있으면 단축키는 동작하지 않는다. 타임라인 슬라이더·색상 선택기는 예외다(단축키 유지).

| 키 | 동작 |
| --- | --- |
| `Ctrl/⌘+K`, `F3` | **명령 팔레트** — 모든 명령 검색. 일치하는 명령이 없으면 그대로 AI에게 요청 |
| `Ctrl/⌘+J` | AI에게 요청(팔레트 AI 모드) · `Ctrl/⌘+I` AI·스크립트 패널 |
| `?` (`Shift+/`) | 단축키 시트 |
| `Ctrl/⌘+S` · `Ctrl/⌘+O` | 프로젝트 저장(.blockshot.json) · 열기 |
| `Ctrl/⌘+Shift+E` | 렌더 패널 |
| `Shift+A` | 인물 추가 (나머지는 메뉴 **추가**) |
| `Shift+D`, `Ctrl/⌘+D` | 선택 오브젝트 복제 (+X로 0.6 m 옆에) |
| `Esc` | 선택 해제 |
| `F` | **선택한 것으로 화면 맞추기(포커스)** — 선택한 인물·소품·카메라(포즈 편집 중이면 그 뼈)가 편집 화면 가운데 꽉 차게. 아무것도 없으면 전체. 카메라·컷 시점에서 누르면 편집 시점으로 바뀐다. 탑뷰도 같이 가운데로 (Maya·Unity·Unreal의 F, Blender의 numpad `.`) |
| `A`, `Shift+F` | 전체 보기 — 모든 인물·소품·카메라가 화면에 들어오게 (Maya의 A, Blender의 Home) |
| 아웃라이너 더블클릭 | 인물·소품: 그것으로 화면 맞추기 · 카메라: 그 카메라 시점 |
| `P` | 경로 찍기 (선택한 인물) |
| `C` | (카메라 시점에서) 카메라 조작 켜기/끄기 |
| `Ctrl/⌘+Alt+0` | 선택한 카메라를 지금 보는 구도로 맞추기 |
| `Alt+1` / `Alt+2` / `Alt+3` | 왼쪽 패널 / 오른쪽 패널 / 타임라인 열고 닫기 (창 폭 1200px 미만이면 좌우 패널은 서랍으로 열리고 `Esc`·바깥 클릭으로 닫힘) |
| `←` / `→` (`Shift`: 10프레임) | 한 프레임 이동 |
| `↓` / `↑` | 선택 오브젝트의 이전 / 다음 키로 |
| `Home` / `End` | 처음 / 끝으로 |
| 우클릭 | 아웃라이너·뷰포트 오브젝트의 상황 메뉴 (복제·삭제·키·경로·굳히기·카메라 시점·AI 연출 요청) |
| `Space` | 재생 / 정지 |
| `K` | 선택한 인물/카메라에 **현재 시간의 키** 추가 (인물: 위치·회전·포즈 / 카메라: 위치·렌즈) |
| `Alt+K` | 선택 오브젝트의 현재 시간 키 삭제 (액션으로 생긴 회색 키 포함) |
| 타임라인 ◆ 우클릭 | 그 키 삭제 (속성 패널의 ◇ 이 시간 키 삭제 버튼도 동일) |
| `Shift+K` | **자동 키** 켜기/끄기 — 켜면 인물·카메라를 움직이거나 렌즈·포즈를 바꿀 때마다 현재 시간에 키 |
| `Delete` / `Backspace` | 선택 오브젝트 삭제 (관련 액션·트랙·샷 참조도 정리) |
| `W` / `E` / `R` | 기즈모 이동 / 회전 / 크기 (소품: 축별 크기 · 인물: 키를 비율 유지로 · 카메라: 해당 없음) |
| `S` | 스냅 켜기/끄기 (이동 0.1 m, 회전 15°) |
| `Ctrl/⌘+Z` | 실행 취소 |
| `Ctrl/⌘+Shift+Z`, `Ctrl/⌘+Y` | 다시 실행 |
| `Shift+R` | 선택한 인물/카메라 **레코딩 시작** (현재 시간부터 재생하며 키보드 조작을 기록) |
| `V` | 자유 시점 (편집) |
| `0` | 컷 재생(샷 순서대로) 시점 |
| `1`–`9` | N번째 카메라 시점 |
| `T` | 화면 배치 전환: 3D → 3D+탑뷰(분할) → 탑뷰 |
| `Esc` | 에셋 배치 / 경로 그리기 취소 |
| `Enter` · `Backspace` | (경로 찍는 중) 완료 · 마지막 점 되돌리기 |

## 🎬 컷 재생(편집) 시점 — 캡컷 / 프리미어 방식

명령은 **선택한 클립** → 없으면 **In/Out 구간** → 없으면 **재생 헤드 아래 클립**에 적용된다.

| 키 / 동작 | 효과 |
| --- | --- |
| `A` / `B` | 선택 도구 / 면도날 도구 (면도날: 클립을 클릭한 위치에서 자르기) |
| `Ctrl/⌘+B` | 재생 헤드 위치에서 자르기 (`Ctrl/⌘+K`는 이제 명령 팔레트) |
| `I` / `O` / `Alt+X` | In 지점 / Out 지점 / 구간 해제 |
| `Delete` / `Backspace` | 선택 클립 리플 삭제, 선택이 없으면 **In/Out 구간 잘라내기**(뒤가 당겨짐) |
| `Ctrl/⌘+X` · `C` · `V` | 잘라내기 · 복사 · **재생 헤드 위치에 붙여넣기**(클립 중간이면 갈라서 끼워 넣음) |
| `Ctrl/⌘+D` | 복제 (선택 뒤에) |
| `←` / `→` (`Shift`: 10프레임) | 한 프레임 이동 |
| `↑` / `↓` | 이전 / 다음 편집점 |
| `Alt+←` / `Alt+→` | 선택 클립을 앞/뒤로 이동 |
| `Home` / `Esc` | 처음으로 / 선택·구간·면도날 해제 |
| 클립 클릭 · `Shift`+클릭 | 선택(+재생 헤드 이동) · 추가 선택 |
| 클립 드래그 | 가장 가까운 편집점으로 이동 |
| 클립 양 끝 드래그 | 트림 (장면 In/Out) |
| 눈금자 클릭·드래그 | 재생 헤드 이동 |
| 소스·보관함 항목 드래그 | 놓은 위치에 삽입 |

## 레코딩 중 (● REC)

| 키 | 인물 | 카메라 |
| --- | --- | --- |
| `W` `A` `S` `D` | 보고 있는 시점 기준 앞·왼쪽·뒤·오른쪽 걷기 | 앞·왼쪽·뒤·오른쪽 이동 |
| `Shift` | 달리기 | 빠르게 이동 |
| `R` / `F` | — | 위 / 아래 |
| `←` `→` `↑` `↓` | — | 좌우 팬 / 상하 틸트 (조준 대상이 없는 카메라만) |
| `Z` / `X` | — | 줌 아웃 / 줌 인 (초점거리) |
| `Space` / `Esc` | 정지 → 키로 저장 | 정지 → 키로 저장 |

녹화 구간의 기존 키는 새 동작으로 교체되고, 구간 밖 동작은 유지된다. 한 번의 Ctrl+Z로 취소.

## 카메라 조작 (📷 카메라 시점에서 🎮 카메라 조작 ON)

| 마우스 | 동작 |
| --- | --- |
| 좌클릭 드래그 | 조준점을 중심으로 카메라 회전(오빗) |
| 휠 | 조준점 쪽으로 다가가기 / 멀어지기 |
| 우클릭 드래그 | 팬 (조준 대상이 인물 참조일 때는 비활성) |

놓는 순간 저장된다(위치가 애니메이션 중이면 현재 시간에 키).

## 편집 규칙

- 기즈모·속성 패널로 위치/회전/렌즈/포즈를 바꿀 때, 그 속성에 **키가 하나라도 있거나**(수동 키·액션) **자동 키가 켜져 있으면** 현재 시간에 키가 추가된다. 그 외에는 기본값(모든 시간)이 바뀐다.
- 수동 키가 처음 생길 때 기존 모션(액션이 만든 키)은 수동 트랙으로 복사되어 유지된다. 이후 해당 속성은 `actions` 대신 수동 트랙이 우선한다(SCENE_SPEC의 "tracks override").
- 모든 편집은 undo 한 단계(최대 100). 파일 열기/AI 임포트는 히스토리를 초기화한다.

## 에셋 배치 · 탑뷰

- **에셋 탭**에서 카드를 고르면(또는 장면으로 끌어다 놓으면) 배치 모드가 된다. 3D·탑뷰 어디서든 **바닥을 클릭**하면 놓이고 선택된다. `Shift+클릭`은 연속 배치, `Esc`는 취소.
- 방에서는 소파·침대가 가까운 벽에 붙어 방 안쪽을 보고, 문·창·거울은 가장 가까운 벽에 걸린다. 그 밖의 소품은 방 안으로 밀어 넣는다. 스냅(`S`)이 켜져 있으면 0.1 m 격자.
- **탑뷰**: 휠 확대, 빈 곳 드래그로 이동, 오브젝트 드래그로 위치, 선택하면 나타나는 **노란 점**을 끌어 방향 회전(스냅 시 15°). 카메라의 부채꼴은 화각, 점선은 이동 경로, **축선** 버튼은 두 인물을 잇는 180° 선(카메라가 같은 쪽이면 초록, 반대쪽이면 빨강).
- `.glb` 파일을 화면에 끌어다 놓으면 모델로 불러온 뒤 바로 배치 모드가 된다.
- **경로 찍기**: 인물을 선택 → 속성 패널의 `🚶 경로 찍기` → 바닥을 차례로 클릭 → `Enter`. 현재 시간에 시작하는 걷기 액션 하나가 만들어지고, 경로가 길면 프로젝트 길이가 자동으로 늘어난다.
